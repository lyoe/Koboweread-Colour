# 构建与安装

## 1. 准备电脑

- **macOS**：装好 Xcode 命令行工具（`xcode-select --install`）。系统自带的 curl、python3、perl、make、zip、cpio 就够用。
- **Linux x86_64**（以 Ubuntu 为例）：

  ```sh
  sudo apt-get install -y build-essential curl unzip zip cpio python3 perl
  ```

## 2. 下载工具链与 Google 镜像

```sh
sh bootstrap.sh
```

脚本会说明哪些文件受 Android SDK 许可约束，你输入 `yes` 表示接受（无人值守时设 `KOBO_ACCEPT_ANDROID_SDK_LICENSE=1`）。下载内容约 650 MB，全部按固定版本和 sha256 校验，然后：

- 工具放在 `tools/`：zig 0.13.0、Temurin JDK 17.0.20.1+1、`android.jar`（platform 24 r02）、`d8.jar`（build-tools 30.0.3）、`aapt2`（8.4.0-11315950），以及在本机编译的 `debugfs`；
- Google 的 Android 7.0 ARM 系统镜像（`armeabi-v7a-24_r07`）解开到 `build/google/`。

## 3. 打包

构建 1.9.7 安装包：

```sh
sh src/package/build-package.sh 1.9.7
```

- 第一次运行会在 `build/keys/lab.jks` 生成你自己的签名密钥，用于启动器和测试应用。请保留它：以后重新打包要用同一个密钥，才能覆盖安装。
- 大约 4–5 分钟，输出 `releases/wereadkobo-1.9.7-日期-local.zip`。

打包脚本会依次完成：
1. 构建运行层、启动器、显示与系统库、JIT 配置库、`e2fsck`、`tune2fs` 等工具；
2. 按 `recipe/v197` 把 Google 镜像的文件、字节补丁、本项目文件、构建产物 组装成 Android 根文件系统，并把 `packages.xml` 里的启动器证书换成你的；
3. 生成 KOReader 插件和安装数据。

## 4. 安装到 Kobo

1. 解压 zip。自行下载与安装包版本一致的墨水屏版微信读书 APK，命名为 `weread-1.9.7.apk` 或 `weread-1.8.8.apk`，放进 `wereadkobo.koplugin` 目录，与 `main.lua` 同级。用 USB 将整个目录复制到 Kobo 的 `.adds/koreader/plugins/`，然后安全弹出。安装时会校验 APK 的 SHA-256，并从中提取所需的原生库。
2. 在 KOReader 里打开"菜单 → 工具（扳手）→ 微信读书 1.9.7（安装）→ 安装微信读书 1.9.7"。
   - 安装需要 5–10 分钟，期间请接上电源。
   - 安装内容放在 `.adds/kobo-weread-home`，包括一个 2 GB 的镜像文件。镜像是带日志的 ext4：阅读器被强制重启或电量耗尽时，下次启动会用日志自动恢复。
3. 按提示重启 KOReader，菜单变为"微信读书 1.9.7（安装版）"。选"Android 启动器"，第一次启动约 1–2 分钟。
4. 在微信读书里同意协议，用微信扫码登录。

**注意**：同一个微信读书账号只能在一台设备、一个版本上保持登录。在这里登录会把其他设备上的墨水屏版挤下线。

## 5. 使用

- 翻页键：上键下一页，下键上一页。按住 1 秒后松开是全刷，用来清除残影。
- 屏幕边缘上下滑动可以调前光。
- 同时按住两个翻页键 2 秒后松开，或按电源键，回到 KOReader，Android 保留在后台。
- 菜单里有"关闭后台 Android"、显示效果、操作说明和运行状态。

## 6. 卸载

在 KOReader 里先选"关闭后台 Android"，然后用 USB 删除 `.adds/kobo-weread-home` 和 `.adds/koreader/plugins/wereadkobo.koplugin`。

## 7. 开关

两版的启动器都有「阅读优化」页。可设置 5 分钟自动休眠、实体键翻页渐显、章节预排版和热门划线用户缓存。电池供电时，自动休眠默认开启。由此触发的休眠唤醒后会切回原微信读书会话。翻页渐显默认关闭，开启后从屏幕边缘分 8 条刷新。设置保存后，重启微信读书会话生效。

也可以在安装目录下手动创建以下空文件，下次启动生效。

| 开关 | 作用 |
|---|---|
| `fast-v197/idle-suspend-disabled` | 关闭微信读书空闲休眠 |
| `fast-v197/page-wipe-enabled` | 启用实体键翻页渐显 |
| `fast-v197/zram-disabled` | 关闭 zram 压缩交换 |
| `fast-v197/skia-disabled` | 字形缓存回到 768 KB |
| `fast-v197/segdict-disabled` | 关书后不释放分词词典 |
| `fast-v197/seglow-disabled` | 分词进程不降低优先级 |
| `fast-v197/fontcache-disabled` | 关闭字号缓存 |
| `fast-v197/poollow-disabled` | 后台线程池不降低优先级 |
| `fast-v197/hwc-disabled` | 关闭 HWC 直接合成。注意：公开版没有附带它的备用显示库 |

1.8.8 把目录名换成 `fast-v188/`。

### 可选的 AOSP 离线拼音

1.8.8 和 1.9.7 共用同一个拼音 APK 和 ARMv7 解码库构建脚本。打包时将 `KOBO_PINYIN_SOURCE` 指向 AOSP `platform/packages/inputmethods/PinyinIME` 的本地 Git 仓库，其中须含有 `src/resident-v197/pinyin/build.sh` 指定的提交。同时设置 `KOBO_AIDL` 为 Android SDK 的 `aidl` 路径，`KOBO_ANDROID_CC` 为 NDK 的 `armv7a-linux-androideabi24-clang++` 路径。沿用上面的安装包构建命令即可将拼音组件打包进去。

安装后在启动器的「阅读优化」中开启「AOSP 离线拼音」，再重启微信读书会话。默认关闭。需要设备端延迟诊断时，可用 `KOBO_PINYIN_TRACE=1` 构建，再在安装根目录的相应 `fast-v188` 或 `fast-v197` 下创建 `ime-trace-enabled` 并重启会话。
