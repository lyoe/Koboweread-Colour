# 微信读书真实触屏页面跳转验证

本轮捕获一次人工单指触摸，经宿主转发器和真实 InputManager 分发到原始微信读书 UID 10007 的聚焦窗口。落点 (379,707)，对应登录页的“用户协议”文字链接；没有点击获取二维码或确认协议。

原始输入事件 25 条，转发 MotionEvent 3 条，完整手势 1 次，过滤帧 0、多指帧 0。最终截图显示应用内“用户协议”页面，顶部标题、底部返回和浏览导航可见，正文空白。它证明真实物理输入已触发原 APK 的页面导航；尚不证明联网、协议正文加载、二维码、登录或阅读可用，也不能确定早期无响应的原因。

持续显示输出 4 帧，最终截图灰度指纹与实际输出帧记录匹配。原 framebuffer 字节恢复一致，两个原 KOReader 进程恢复 sleeping 状态；最终审计没有残留 Android 进程、实验模块、挂载或 loop 设备，原内核启动标识未变。

APK 未修改、未重签。本轮没有确认协议或登录。
