## 测试安排

先测 1.9.8，保持 API 24、原生 1264×1680/320 DPI、30Hz、REAGL＋文字增强不变。在设备空闲且原镜像卸载时制作 2 GiB 独立镜像，复制前后检查原文件元数据并核对两份镜像 SHA-256。保留原 2.1.2 镜像与菜单入口。仅在副本中将原应用数据移出工作路径，避免新版数据库影响旧版；可能需要重新登录。

1.9.8 的安装探针仅替换固定 APK 摘要，并在真实 PackageInstaller Session 增加显式允许降级标志，包名与签名校验保持不变。副本首次启动安装，后续复用；首次安装和编译时间不计入正常启动对比。PMS 应继续保留 UID 10007，实际结果仍须核验。

1.5.2 需要单独适配目标 SDK 28 和声明的 `:quick`、`:res_can_worker`、`:seg` 进程；不能直接套用 2.1.2 的固定目标 SDK 31 与仅 `:seg` 白名单，也不能无差别放开任意子进程。它的数据库服务名称也从当前适配使用的 `com.tencent.weread.aidl.DBDataService` 变为 `com.tencent.weread.app.aidl.DBDataService`。先判断实际调用，再做有限扩展。

## 比较方法

依次验收安装、实际窗口、用户扫码登录、书架、同一本已下载书的正文/翻页/注释/返回/重开与退出清理。记录至少三轮正常启动、首次/重复开书、返回书架与可用内存，区分总等待、黑屏、面板刷新；关闭重型采样。旧版和新版均需预下载同一本书、保持相同显示设置，再比较稳态结果。包体和最低系统要求不能直接推出速度。

详细元数据见 `apk-metadata.json`。本目录安装补丁仅对应已核验的 1.9.8 文件，不是通用降级工具。
