# 无焦点切页与真实窗口所有者

第 57 轮用户继续操作并返回书架时，WMS 的 mCurrentFocus 为 null，mFocusedApp 指向微信读书主界面。旧辅助程序因此关闭连接，runner 退出 119。该轮 20 次物理手势、202 个事件、36 帧显示，未见 Java 致命异常或优先级异常；正常清理已确认。

新辅助程序匹配实际焦点 WindowState 的 UID 与 package，而非仅相信窗口标题。焦点过渡时短暂等待；不能确认时跳过整次手势，不注入其他应用，也不将跳过事件记为应用接受。ACK 2 与 skipped_events 使两端日志可区分实际注入与跳过。

以实机 WMS 格式为夹具完成 7 项解析检查，包括 null 焦点、错误 UID、错误包名、包名前缀和伪造窗口标题。夹具原文可能含私人应用信息，仅保留本地；此处不分发。解析检查不等于物理输入回归，后者待用户通过新菜单验证。
