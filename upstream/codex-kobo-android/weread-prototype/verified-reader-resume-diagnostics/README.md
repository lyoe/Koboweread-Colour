# 阅读页恢复与线程诊断

第 52 轮原版微信读书自行恢复上次的 ReaderFragmentActivity，虚拟扫描输出已显示真实书籍封面、正在下载指示和左滑阅读提示。它没有回到书架。仅看到封面不能计为正文可读。

主进程及 :seg 子进程的 ART 线程记录完整取得，采样时两者主线程均位于 MessageQueue.nativePollOnce。该采样证明当时未持续卡住主线程，不能反推上一轮输入超时的具体原因。

旧测试入口仅接受书架页，因此退出 61，未打开物理触控窗口。后续修复仅在人工交互模式允许真实书架或阅读 Activity，并继续检查原 APK 签名和 UID。私有画面及完整线程记录没有分发。

第 54 轮已接受恢复的阅读 Activity，但原生阅读页尚未实例化 WebView，旧映射断言退出 105。后续仅在人工交互且真实阅读页已显示、应用进程尚无任何 WebView 库映射时允许继续；已加载 WebView 的情形仍须核对实际映射，外层组件哈希校验仍保留。
