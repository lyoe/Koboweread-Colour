# 人工扫码登录与登录保留

用户通过 Forma 上原版微信读书的真实触控界面自行同意协议、获取二维码并在手机微信确认，反馈“已登录，出现主界面”。重新启动后，用户进一步确认“登录保留，内容没有刷新出来”。这两项采用用户确认作为证据，没有自动读取或公开账号内容。

首轮磁盘满导致网络观察器退出，runner 退出 118；下一轮触控转发中断，退出 119。增加触控等待并使用等待接受事件的模式后，第三轮完整退出 0，但没有人工手势，画面在三分钟内仍停留“加载中”，不能计为书籍内容或翻页成功。线程采样显示 UI 线程等待事件，多条工作线程在解析响应及反射构造对象，后续第 50 轮启用 JIT 后，真实书架已加载；开书仍因 :seg 子进程拒绝而失败，见相邻 verified-bookshelf-segment-failure。

私有镜像先扩至 1 GiB，后因同步缓存继续增长，在备份最新应用数据后扩至 1.25 GiB；扩容前后文件系统检查均通过。账号、登录二维码、书库截图、完整私有镜像和原始登录后日志不随源码包分发。
