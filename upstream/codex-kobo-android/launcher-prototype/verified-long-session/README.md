# 30 分钟上限与手动退出

长会话模式已通过一次实机启动、阅读与手动退出。用户反馈阅读和退出正常，但启动缓慢且偶尔失败。设备日志记录 max_seconds=1800、exit_holds=1、退出码 0，6 个正常手势、43 个事件，无跳过或拒绝事件；原 framebuffer 恢复字节一致，KOReader 空闲策略已释放。未独立测量本次实际交互时长，不能把配置上限记为已完成整整 30 分钟长测。原有三分钟入口保留。

在屏幕左上角 60×60 虚拟像素区域，单指保持两秒后松手请求退出。短按会转发原来的手势；提前移动超出范围会取消退出判定并转发手势，多指或异常触控会取消退出判定。退出手势不向微信读书注入点击，松手后才释放输入抓取，避免把未结束的触摸交给 KOReader。

原有网络、显示和输入辅助组件的时限已同步延长：物理输入及会话 1800 秒，显示 1860 秒，Java 输入 1830 秒，DNS/网络观察 2400 秒（包含初始化余量）。就绪文件包含明确时长，状态查询不再固定认为三分钟后失效。

菜单插件使用当前设备 KOReader 的 PluginShare.pause_auto_suspend 与成对的 preventStandby/allowStandby。多界面实例共享引用计数，运行完成后通过原始 InputEvent hook 重置空闲计时并恢复原先策略，没有修改保存的休眠设置。失败启动、重复持有、交叠界面、PID 复用和重启前遗留锁的无界面测试均通过。返回 KOReader 后再使用休眠，Android 内休眠仍未验证。

本目录只含自制测试和筛选后的结果，不包含账号、书籍内容或原始应用日志。
