# 用真实就绪检查替代部分固定等待

日常 reading 配置对宿主网络观察、DNS、属性服务、日志接收和进程服务检查新启动服务的实际存活状态、专属 READY 标志及对应文件/套接字。父进程在 fork 前清空标志日志，避免旧日志与旧套接字形成假就绪。已停止、已退出、僵尸或无效 PID 不计为就绪。

安装器使用匹配协议的 ping-only 探测，严格要求响应为 0，不发送创建或销毁应用数据的命令。响应失败或服务启动延迟时有界重试；始终未就绪会明确失败。图形、存储、音频、传感器等服务暂时保留原等待，完整诊断配置也保留原有流程。

本机协议测试覆盖实际 UNIX 套接字、错误/畸形回复、无额外命令及测试应用数据保持；设备测试覆盖延迟标志、延迟套接字、停止/死亡进程、陈旧标志及超时，均通过。首次实机环境准备 14.68 秒，此前基线约 21 秒；框架阶段 29.20 秒，总计约 145.98 秒到交互就绪。单次结果不能替代连续稳定性验证。

本目录不包含原始应用日志、账号或书籍内容。完整三十分钟运行结果待补充；此前十轮通过的基线组件身份仍单独保留在 verified-startup-bootstrap。
