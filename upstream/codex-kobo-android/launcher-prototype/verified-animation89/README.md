# 第 89 版：关闭 Android 动画的单项试验

第 88 版窗口切换触控回归获用户确认正常，等待时间大致不变。当前阅读窗口中只读查询确认：Android 的窗口、过渡、控件动画缩放均为 1，SurfaceFlinger 刷新周期为 33333333 ns，约 30Hz。它仍是软件合成；这不代表墨水屏能以 30Hz 实际显示。

本轮通过根用户 IWindowManager 接口把三项动画设为 0，并立即读回确认 `[0,0,0]`。原 `[1,1,1]` 已保存为私有镜像 `/lab/reading-animation-scales-before89.txt`，根用户所有、0600。修改只在私有 Android 环境中，可能随其设置保存；不自动随阅读结束恢复。`ReadingPerfProbe restore` 在 Android 服务运行时可恢复备份，成功读回后删除备份；该恢复路径已在下一次启动期间真实执行，读回确认恢复为 `[1,1,1]`，备份随后删除。

保持原 JIT 参数、APK、odex、刷新波形和 SurfaceFlinger 帧率。目的是观察减少动画能否减轻过渡期绘制负担；用户反馈改善不大，未证实有意义的提速，三项动画已恢复原值。当前是同一次已启动阅读窗口，复测应主要比较重复开书约 16 秒、返回书架 8～11 秒，不能把暖缓存下的再次开书与首次 35 秒直接当作严格对照。

备份格式测试验证三项浮点值原样往返及空值、缺项、多项、NaN、无穷、负数、越界拒绝。生产辅助程序限制根用户及固定模式和路径，恢复时校验文件类型、UID、权限及长度。它不读取或更改账号、书库与原 APK。设备已验证关闭并读回，人工对比已完成，收益有限。

源代码中 `inspect` 只读动画及合成器周期，`off` 拒绝覆盖既有备份，`restore` 只恢复该备份。辅助进程完成后退出，不常驻占用阅读内存。原始应用日志和画面只保留在私有工作目录。
