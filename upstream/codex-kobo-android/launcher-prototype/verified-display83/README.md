# 第 83 版：文字灰阶与 REAGL 刷新测试

用户确认主要问题为字体发灰和翻页残影。本轮仅更改显示桥接与显示选项，保留第 80 版 Android 环境及原运行缓存；第 82 版预编译候选未安装。

三个显示选项为标准、REAGL、REAGL＋文字增强，后者为当前默认。重开 KOReader 后可在“微信读书（测试）→显示效果”选择，下次启动生效；阅读运行期间禁止切换。启动器及原生桥接均校验固定值。

仅在识别为 Forma 377/380 时启用 REAGL 普通刷新，初次、周期和手动清屏继续使用 GC16，并等待每次更新完成。REAGL 提交失败时尝试 GC16 全刷并停止继续使用 REAGL。实机已识别 377，记录到多次 REAGL 更新完成与手动 GC16，全程尚未完成验证。沿用 KOReader 对 Mk7 设备普通刷新使用 REAGL 的策略，不混用 A2 或强制黑白标志。

文字增强使用 3/8 二次曲线与 5/8 恒等曲线混合，128 灰阶映射为约 104，黑白端点不变。保留渐变与抗锯齿，不使用二值阈值。此转换作用于整幅灰度画面，插图和封面也可能略暗；它不是 APK 内部的字体加粗或字体替换。虚拟分辨率仍为 720×960，放大到 1440×1920，不能称为原生高分辨率排版。

主机 C 测试通过端点、单调性、16 个灰阶区分和标准模式恒等检查；设备上的无界面 Lua 测试通过显示选项持久化、非法值、默认值、运行中禁止切换，并通过已有启动进度与待机策略回归。用户已确认文字与残影都有改善。本轮交互运行 271.63 秒，由实体双键主动退出，返回 KOReader、原画面恢复与组件清理通过；尚未完成完整 30 分钟长测。后续仅将退出恢复波形明确设为 GC16，文字曲线和普通刷新策略保持不变。原始页面和认证日志保留在私有工作目录。

第 83 版显示测试采用暂停 KOReader 的模式。后续五秒真实退出/恢复交接已通过，第 85 版独立阅读实验已安装，阅读回归待完成，见 [独立运行记录](../handoff-prototype/README.md)。
