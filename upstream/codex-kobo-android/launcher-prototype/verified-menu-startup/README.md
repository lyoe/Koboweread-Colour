# KOReader 菜单启动修复

用户确认菜单可见，但首次菜单运行退出 10。实际日志显示 UID 1000 读取 config.disable_network 被拒绝；菜单入口的 umask 077 被 Android 初始化继承，使共享属性路径仅 root 可读。

运行层现在显式使用 umask 022，应用子进程仍自行设置其限制；临时 WebView 原生库目录显式为 0755，避免外层菜单的创建掩码使它们成为 0700。菜单本身继续使用限制性创建掩码。

同一个设备本地入口随后实际进入触控窗口，用户确认翻页正常。点击正文注释时，InputManager 拒绝某个事件，旧辅助程序主动关闭连接，runner 退出 119。此次无 Java 致命异常，不能描述为原 APK 崩溃。

第 62 轮修改：单个注入拒绝只取消该手势，ACK 3 明确表示拒绝；后续事件跳过至手势结束，再接受新手势。独立计数 rejected_events，与 accepted 及 skipped 分开。基于真实 native send_event 的设备 socketpair 测试验证四种 ACK 分类及计数，没有打开物理输入设备。第 63 轮实际注释交互已由用户确认通过。

## 第 63 轮完整回归通过

用户从 KOReader 菜单启动，并确认注释打开、翻页、回到书架再打开书籍均正常。完整会话退出 0，23 次物理手势、241 个协议事件、40 帧墨水屏更新；3 个事件明确跳过，0 个事件被注入接口拒绝。拒绝恢复分支的 ACK 分类由独立 socketpair 测试覆盖，本轮没有实际触发该分支。

断开电脑 SSH 后会话仍继续运行。结束后原 framebuffer 字节一致，KOReader 恢复，WebView 临时组件恢复、镜像卸载、实验模块清理和启动锁释放均通过。三分钟时限依旧保留，尚未验证长时间阅读或休眠。
