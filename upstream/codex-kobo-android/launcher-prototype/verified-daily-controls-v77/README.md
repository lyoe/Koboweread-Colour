# 第 77 版：单键长按全刷与翻页方向

根据用户实测反馈，将按钮在右侧竖屏时的操作改为：

- 上翻页键短按松手：下一页。
- 下翻页键短按松手：上一页。
- 任一翻页键按住至少 1 秒后松开：全刷一次，不额外翻页。
- 两键同时按住至少 2 秒后全部松开：退出。双键短按不执行操作。
- 左上角长按两秒退出和电源键松开返回 KOReader 保留。

使用单调时钟，从真实按下到松开计算时长，忽略内核重复事件；只有一次完整松手产生一个动作。双键组合优先于单键长按，启动前已按住的键先释放才能使用。全刷沿用第 76 版已实机确认的原子请求、GC16 刷新及清理流程。KOReader 操作说明已更新，需重开 KOReader 载入；按键规则在新一轮微信读书启动时生效。

ControlsTest.c 对上下方向、1 秒临界值、长按重复、长按后的短按、两种双键顺序、组合键优先级、启动时按住及电源键退出完成断言。实际按键与显示结果见 verification.json。回滚仅需恢复第 76 版 touch-forward 与插件说明，不涉及账号和书籍数据。

实机复测已通过：用户确认新方向与两枚单键长按全刷均正常，且无额外翻页。日志记录 16 次已接受的实体翻页、3 次手动全刷请求和 3 次实际手动全刷，以及 1 次双键长按退出；运行 65.04 秒，退出码 0，画面恢复字节一致，未发现 Java/原生崩溃或微信读书 ANR。退出后实验进程、模块、挂载及 loop 均已清理，原 KOReader 已恢复。该结果未覆盖完整 30 分钟或休眠。
